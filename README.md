# GamingX Overlay

Гейминг-оверлей поверх **всех приложений** (включая игры и полноэкранные окна): счётчик FPS с графиком, системная информация, пинг, прицел и панель оптимизации по горячей клавише **Ctrl+Alt+X**.

## Возможности

| Модуль | Что делает |
|--------|------------|
| **FPS + график** | Реальный счётчик кадров со.sparkline-графиком последних секунд |
| **CPU / RAM / GPU** | Загрузка процессора, ocupada/всего оперативной памяти, модель видеокарты |
| **Батарея** | Процент заряда и состояние зарядки (ноутбуки) |
| **Uptime** | Время работы системы |
| **Пинг** | TCP-проверка до любого хоста:порт (например, игровой сервер) |
| **Прицел** | Центральный прицел на экране |
| **Game Boost** | Схема питания «Максимальная производительность» + очистка временных файлов |
| **Менеджер процессов** | Завершение любого процесса по PID |

## Управление

- **Ctrl+Alt+X** — открыть/закрыть панель управления (переназначается в меню).
- В панели можно включать/выключать модули, менять позицию оверлея (4 угла экрана), прозрачность и размер шрифта, задать хост для пинга и порог тревоги FPS.
- Кнопка «Разблокировать перемещение» позволяет перетащить оверлей за заголовок в любое место экрана.

## Шрифт

Используется **Orbitron** — геометрический футуристичный шрифт в стиле игровых HUD (локальный файл `fonts/Orbitron-Variable.ttf`, лицензия SIL OFL, источник: Google Fonts). Работает без интернета.

## Запуск

```bash
# 1. Установить зависимости (скачает бинарник Electron с GitHub)
npm install

# 2. Запустить оверлей
npm start
```

После запуска оверлей сразу появится в правом верхнем углу экрана поверх всех окон. Откройте меню по **Ctrl+Alt+X**.

## Технологии

- **Electron** — оверлейное окно (прозрачное, безрамочное, `alwaysOnTop`, клик сквозь оверлей), глобальные горячие клавиши.
- **systeminformation** — CPU, RAM, GPU, батарея, время работы.
- Vanilla JS + CSS (без фреймворков).

## Примечание

В данной sandbox-среде бинарник Electron скачать невозможно (ограничение TLS на GitHub release assets), поэтому `node_modules` не развёрнут здесь. На вашей машине `npm install` пройдёт обычным образом.
