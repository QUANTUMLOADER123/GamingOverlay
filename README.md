# GamingX Overlay

Гейминг-оверлей поверх **всех приложений** (включая игры и полноэкранные окна): счётчик FPS с графиком, системная информация, пинг, прицел, панель оптимизации Windows и системный трей. Горячая клавиша меню — **Ctrl+Alt+X**.

## Стиль

Оформление в духе отладочных панелей 2000-х: угловатый интерфейс **без скруглений**, терминальный шрифт Orbitron (локальный файл `fonts/Orbitron-Variable.ttf`, лицензия SIL OFL), неоново-зелёный текст на чёрном, сканирующие линии, серебристые рамки.

## Возможности

| Модуль | Что делает |
|--------|------------|
| **FPS + график** | Счётчик кадров со sparkline-графиком, подсветка при падении ниже порога |
| **CPU / RAM / GPU** | Загрузка процессора, память, модель видеокарты |
| **Батарея** | Процент заряда и состояние зарядки |
| **Время / Пользователь** | Текущее время и имя пользователя системы |
| **Сеть** | Загрузка канала (↓/↑ КБ/с) и имя интерфейса |
| **Диск** | Занято/всего на системном диске |
| **Пинг** | TCP-проверка до любого хоста:порт |
| **Прицел** | Центровой прицел на экране |

## Управление

- **Ctrl+Alt+X** — открыть/закрыть панель управления (переназначается в меню).
- Панель: модули оверлея, позиция (4 угла), прозрачность, размер шрифта, хост и порт пинга, порог тревоги FPS.
- Кнопка **Разблокировать** позволяет перетащить оверлей за заголовок в любое место экрана.
- Системный трей: быстрый доступ к Game Boost, схеме питания, автозапуску и выходу.

## Оптимизация Windows (все в меню)

- **Game Boost** — схема питания «Максимальная производительность» + очистка `%TEMP%` + игровой режим (отключение Game DVR / Game Bar)
- **Питание: максимум** — `powercfg /setactive SCHEME_MIN`
- **Очистка TEMP / Prefetch / C:\Windows\Temp**
- **Сброс DNS** — `ipconfig /flushdns`
- **Сброс Winsock / TCP/IP** — `netsh` (требуется перезагрузка)
- **Очистка кэша обновлений Windows** (SoftwareDistribution)
- **Очистка кэша иконок** (проводник перезапускается)
- **Оптимизация сетевого стека** — отключение автонастройки TCP, ECN, меток времени
- **SFC /SCANNOW** и **DISM Restore Health**
- **Приоритет процесса** и завершение по PID

## Системный трей и автозапуск

Оверлей висит в трее рядом с часами. В контекстном меню трея можно быстро запустить Game Boost, сменить схему питания, включить/выключить автозапуск с Windows и полностью выйти из программы.

## Запуск в разработке

```bash
npm install
npm start
```

## Сборка .exe (Windows)

Собрать установщик и портативную версию можно командой:

```bash
npm run pack   # или npm run dist
```

Для этого на машине должна быть установлена утилита **`nsis`** (для целевого типа `nsis`) и доступ в интернет для скачивания бинарника Electron. Результат появится в папке `release/`.

> ⚠️ В данной sandbox-среде бинарник Electron скачать невозможно (ограничение TLS на GitHub release assets), поэтому `node_modules` и готовый `.exe` не развёрнуты здесь. На своей машине `npm install` и `npm run dist` пройдут обычным образом.

Иконка приложения — `build/icon.png` (PNG). Для полноценного `.exe` на Windows рекомендуется сконвертировать её в `build/icon.ico` (любым онлайн-конвертером PNG → ICO) и указать в `package.json` (уже прописано: `"icon": "build/icon.ico"`).

## Технологии

- **Electron** — прозрачное безрамочное окно `alwaysOnTop`, глобальные горячие клавиши, системный трей, автозапуск.
- **systeminformation** — CPU, RAM, GPU, батарея, сеть, диск, пользователи.
- Vanilla JS + CSS (без фреймворков).
